# 模板多样性与公众号排版

> 2026-11-10 实现。两件事：
> 1. **布局变体** —— 让不同客户站一眼能看出不同（此前只有颜色/圆角不同）
> 2. **公众号排版** —— 富文本导出成能粘进微信编辑器的文章

---

## 一、布局变体

### 分层

主题原本只有两层（色板 + 质感），改不了「体格」——所以站还是长得一样。
现在加第三层：

| 层 | 属性 | 改什么 |
|----|------|--------|
| 色板 | `theme.variant` | 颜色（forest / slate / amber） |
| 质感 | `theme.style` | 圆角、阴影、边框的调性 |
| **布局** | **`theme.layout`** | **版心宽度、字体气质、区块节奏、栏数** |
| 密度 | `theme.density` | 间距与正文字号 |

### 四套布局

| 变体 | 特征 | 适合 |
|------|------|------|
| `centered` | 窄栏居中（1080px），克制稳重 | 传统 B2B、制造、政企 |
| `split` | 宽版心（1280px），两列网格，横向节奏 | 产品、SaaS |
| `editorial` | 衬线标题（Songti/Georgia）、窄版心（980px）、大留白、卡片去边框改顶线 | 咨询、律所、内容站 |
| `bold` | 超大标题（最高 4.5rem）、主色满幅 hero、卡片无边框大圆角 | 消费、初创、活动 |

**四套的差异不只在颜色** —— 版心宽度、标题字号、字体族、栅格列数、
区块背景、卡片边框全不一样。实测截图确认过。

### 实现方式

全部落在 CSS 变量与选择器上，**组件 markup 不变**：

```css
[data-layout="editorial"] {
  --container-max: 980px;
  --prose-max: 64ch;
  --hero-title-size: var(--text-5xl);
  --font-display: "Songti SC", Georgia, serif;
}
```

所以加一套布局变体不用复制骨架，也不影响另外几套。

### 中文站的坑

`editorial` 的「首段下沉首字」是西方杂志传统，
**汉字放大 3 倍会非常怪**（实测「已」被放大后像图标）。
所以限定 `[lang="en"]` 才生效，中文站不受影响。

### 外观配置存在哪

`modules.json` 的 `appearance` 字段 —— 后台管的机器可写层。

**为什么不放 site.ts**：site.ts 是「人写、机器不碰」的内容包（分层铁律）。
外观是「客户想要什么样子」的决策，属于后台管辖；
而且换外观不该动内容包（改内容包要走代码评审，太重）。

构建时**后台的配置覆盖手写的 theme** —— 与 plan 和内容包的关系一致。

```ts
mergeAppearance(base.theme, appearance)  // 后台的非空项覆盖手写
```

### 后台怎么选

模块视图最右新增「外观」栏：布局变体 / 质感 / 色板 / 密度 / 主色，
每项带色板预览图。选定后随编排一起保存，发布时写进
`modules.generated.ts` 的 `appearance` 导出。

## 二、公众号排版

### 为什么不能直接用网页的 HTML

微信编辑器（以及大多数富文本编辑器）会：
- **剥离 `<style>` 标签与 class 属性**
- 只保留**内联样式**（`style="..."`）
- 过滤部分标签与自定义属性

网页上好看的类样式，粘到微信里会变成一团白。
所以公众号排版是**另一套渲染** —— 每个节点直接带 style 属性。

### 排版主题

| 主题 | 强调色 | 适合 |
|------|--------|------|
| 简洁 | `#576b95` | 默认微信样式 |
| 微信绿 | `#07c160` | 通用 |
| 商务蓝 | `#1a73e8` | 企业服务 |
| 政务红 | `#c9302c` | 政务/政策 |
| 暖橙 | `#e8684a` | 消费/活动 |

主题**只改视觉属性**（字号、颜色、间距、引用样式、代码框）——
**内容一字不改**，保证 AI 引用的是原文（GEO 底线）。

排版元素：
- 标题：强调色 + 左侧竖线
- 引用：强调色左边框 + 浅底
- 代码块：浅底 + 等宽字体
- 列表项：强调色序号/项目符号
- 表格：细边框 + 表头浅底
- 分割线：淡灰横线

### 安全

- 所有文本转义（`<img onerror=...>` 会被转成实体）
- mark 只放行白名单（bold/italic/underline/strike/code/link）
- link 只放行 `http/https/mailto/` 与站内相对路径，`javascript:` 被丢弃

### 后台怎么用

第三个标签页「公众号」：

1. 选条目（手工创作的优先，知识库来源的也可排 —— 原文来自知识库）
2. 填标题与作者
3. 选排版主题
4. **实时预览**（就是最终粘出去的 HTML，所见即所得）
5. 「复制富文本」→ 粘进微信编辑器
   「复制纯文本」→ 纯文字场景

预览与复制走**同一个服务端接口** `/api/wechat/render`，
排版逻辑只有一份（geo-kit 里），浏览器端不重复实现。
